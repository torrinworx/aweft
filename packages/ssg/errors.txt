<whatever the far end refused for>: Handle this reason where the ask was made, or fix the module that refused it.
bad-entries: Answer an array of objects from entries(), one per page, an empty array for none, or null to say you cannot list them.
bad-entry-value: Answer a value with no empty, . or .. segment in it; those name a place rather than a page.
bad-status: Write 200, or a whole number from 400 to 599 such as 404 or 410, as the status meta's content.
invalid-config: Hand each module as its factory answered it, from imports; one that reads undefined is spelled differently from its name in deps.
invalid-config: Pass modules, an object holding each module a page may ask under the name it asks by.
invalid-config: Pass page, the function that builds the page from a router and a client.
invalid-config: Pass the gate the server runs: open, or the auth/Gate instance named in deps.
invalid-config: Set renders to a whole number of renders at once, 1 or more.
invalid-config: Set timeoutMs to a positive number of milliseconds, at most 2147483647.
locale-invalid: Write a BCP 47 tag such as fr or fr-CA.
locale-needed: Name the language the pages are written in as locale; its pages stand unprefixed and every other language under its tag.
locale-twice: Leave the source language out of locales: its pages stand unprefixed and need no catalog.
missing-parameter: Answer every :name and *name in the act key from entries(), as a string.
no-lookup: Pass the page's document, or an object whose getElementById finds the answers script by its id.
no-shell: Build the page first, so dir holds the index.html the bundler writes, or point dir at the directory it wrote.
not-a-page: Ask for a URL the site has; walk() answers the list, and the fallback is written once as 404.html.
not-a-path: Write each page at the path its URL names; a . or a .. in it names a place rather than a page.
not-data: Send arguments JSON.stringify can carry.
not-handed: Hand the module to createPages in modules, under the name the page asks it by.
not-shared: Render the waiting state from handle.document, as a browser shows it until the document arrives; a page that waits on ready is answered with the shell.
outside-out: Keep every page URL under the site root; a parameter that answers .. is not a page.
refused: Sign in, or ask for something the gate allows.
shell-body: Give the page shell a body element after its head; the page's markup goes inside it.
shell-body-content: Move it into the head or into a component; the generated body holds the page's markup and a hydration refuses anything else.
shell-head: Give the page shell a head element; the stylesheet and the page's head tags go at the front of it.
